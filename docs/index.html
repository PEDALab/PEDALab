Recent Publications

Latest research contributions to the field

Deep Learning Approaches for Crop Disease Detection in Precision Agriculture

admin, Michael Chen, Emily Rodriguez

*IEEE Transactions on Agricultural Engineering, 45*(2), 2024

A deep learning framework achieving 95.3% accuracy in automated crop disease detection using CNNs with attention mechanisms, validated through extensive field trials.

PDF GitHub Project Page
Computer Vision-Based Yield Estimation for Precision Agriculture

Jonathan Jaramillo, Justine Vanden Heuvel, Kirstin Petersen

*Journal of Agricultural Robotics, 2*(1), 2021

A computer vision-based deep learning model for accurate and non-invasive crop yield estimation using drone and ground-based imagery, achieving 0.92 R-squared.
